# EAG16: Multi-Agent System with Self-Iterating Agents

## 📁 Project Overview

This is the **EAG16** project folder containing a sophisticated multi-agent system that combines planning, execution, and self-iteration capabilities to handle complex tasks through coordinated agent workflows.

## 🎯 What's Inside

This folder contains the complete implementation of a **NetworkX Graph-First Architecture** with multiple specialized agents that can:

- **Plan complex workflows** using a dedicated PlannerAgent
- **Self-iterate** to improve their outputs through multiple passes
- **Execute code** and generate static assets (HTML, CSS, JS)
- **Format comprehensive reports** with consulting-grade quality
- **Retrieve external data** using web search and document tools
