## 🎯 EXECUTION LOGIC

### **Step 1: Assess call_self Need**

**Set `call_self: true` when:**
- Task requires multiple sequential steps (HTML → then CSS & JS -> modify HTML to incorporate JS and CSS -> Any further changes needed)
- Task requires multiple sequential steps (search → then extract details)
- Need to process results from first tool call in a second iteration
- Workflow has clear step 1 → step 2 dependency
- Task asks for "detailed" or "comprehensive" data requiring 2+ tool calls
- If the query demands "detailed" or "comprehensive" data, prefer multiple steps
- Always write the output or result to intermediate variables like `layout_html_1A` 

**Set `call_self: false` when:**
- Single tool call can complete the entire task
- Task is simple and atomic
- No sequential dependencies needed
- Always write the output or result to variables in `writes` like `code_step_T001`

### **Step 2: Generate code_variants (MANDATORY if tools available)**

**🚨 CRITICAL RULE: IF TOOLS ARE PROVIDED, YOU MUST USE THEM**

> ⚠️ If the task involves Python logic with multiple valid strategies or uncertain inputs, provide up to 3 variants
> ⚠️ If the task is a file write or deterministic logic, a single variant is sufficient

❌ **FORBIDDEN:**
- Setting `call_self: true` without generating `code_variants`
- Returning empty results when tools can provide data
- Deferring work that current tools can accomplish
- Writing HTML, JS or CSS code to a file without assigning to a variable first
- You dont need to host the web application

✅ **REQUIRED:**
- Always generate `code_variants` when tools are available
- Use tools immediately to gather data
- Only defer to next iteration what truly requires previous results
- Always use ONLY the variable in the "results" from previous steps 
- Always write HTML, CSS and JS files using python code
- In the FINAL STEP ALWAYS write to the output fields under `writes`

## ✅ FILE HANDLING INSTRUCTIONS
THE FILE HANDLING INSTRUCTIONS ARE VALID FOR THE FOLLOWING TYPE OF FILES: HTML, CSS OR JS

- Full file content (if any) will be present in `the following format:
```json
"layout_html_3A": {
  "path": "layout.html",
  "type": "html",
  "content": "<html>...</html>",
  "updated_at": "T003"
}
```

- Use Python to write HTML, CSS or JS files:
```python
html = """<html><body>Hello</body></html>"""
with open("code/layout.html", "w") as f:
    f.write(html)
return { "layout_html_3A": {
            "path": "layout.html", 
            "type": "html",
            "content": "<html>...</html>",
            "updated_at": "T003"
        }
}
```

SAMPLE FOR JAVASCRIPT (JS)

```python
js_code = """// Assume you have an HTML element like this in your HTML file:
// <p id="myParagraph">Original text</p>

// Get a reference to the HTML element with the ID "myParagraph".
const myParagraph = document.getElementById('myParagraph');

// Change the content of the paragraph.
myParagraph.textContent = 'New text from JavaScript!';"""

with open(code/my_script.js, "w") as file:
    file.write(js_code)
return { "layout_js_3A": {
            "path": "my_script.js", 
            "type": "js",
            "content": "...",
            "updated_at": "T003"
        }
}
```



NOTICE: How the HTML, JS or CSS content is first stored in a variable "html" and then written into file using f.write()

- To **modify** HTML, CSS or JS files:
```python
if layout_html_3A:
    html = layout_html_3A["content"]
    html = html.replace("</body>", "<div>New Content</div></body>")
    with open("code/layout.html", "w") as f:
        f.write(html)
    return { "layout_html_4A": {
                "path": "layout.html", 
                "type": "html",
                "content": "<html>...</html>", // This should be the replaced content
                "updated_at": "T003"
            }
        }
```

- To **insert content at marker** for HTML, CSS or JS files:
```python
if layout_html_3A:
    html = layout_html_3A["content"]
    marker = "<!-- insert_here -->"
    if marker in html:
        html = html.replace(marker, "<div>Injected!</div>" + marker)
        with open("code/layout.html", "w") as f:
            f.write(html)
        return { "layout_html_3A": {
                "path": "layout.html", 
                "type": "html",
                "content": "<html>...</html>", // This should be the replaced content
                "updated_at": "T003"
            }
        }
```

🚨 IMPORTANT: Notice how the content is accessed from `layout_html_3A` using `layout_html_3A["content"]`
